# 好运刮刮 · guaguale

虚拟积分刮刮乐，提供浏览器页面和 Android WebView 应用。网页使用原生 HTML、CSS、JavaScript，无需 npm 安装或前端构建；Android 将网页资源打包进 APK，可离线运行。

## 功能

- 独立选票页、刮奖页和设置页，适配手机布局与安全区域。
- 支持触摸、鼠标连续跨格刮奖、一键刮开及键盘操作；从空白处、已揭晓格子和分区标题处滑动可上下浏览。
- 每张票使用包含大写字母和数字的 16 位随机编号。
- 本地账号初始 10,000 积分，按票价扣款，中奖积分自动累加。
- 设置页可调整整张票至少中奖一次的概率，保存后用于新票。

## 积分与保存

首次刮开票券时扣除票价，同一张票只扣款一次。中奖后自动入账，重复揭晓不会重复结算。已付费且未完成的票券需继续刮完，再更换票券。

账号、余额、票号、当前票券和已揭晓格子保存在本地 `localStorage` 的 `scratch-account-v1` 中。重新打开页面或应用会恢复数据；尚未完全揭晓的局部涂层轨迹不跨进程保存。

当前账号为本地账号，尚无服务器登录或跨设备同步。电脑浏览器与 Android 应用各自保存数据；浏览器不同 origin 的存储也相互独立，例如 `localhost` 与 `127.0.0.1` 不共享账号。清除站点或应用数据、卸载应用会删除本地记录；同签名覆盖安装保留应用数据。

## 概率设置

在选票页右上角点击「设置」，可通过滑块或数字输入调整概率，也可选择快捷值或恢复默认。

- 范围为 **0%～100%**，步长 **0.1%**，默认 **10%**，所有票种统一适用。
- 表示整张票至少中奖一次的概率；不是每个格子的中奖概率，也不表示积分返还率。
- 点击「保存设置」后，从下一张新生成的票开始生效。当前已生成票券的结果、余额和刮奖进度保持不变。
- 每张票独立随机。例如 10% 表示长期平均约 100 张有 10 张中奖，不保证每 10 张固定中奖一次。
- 设置单独保存在本机 `scratch-settings-v1`，重启后保留。

该设置页属于本地模拟功能；当前概率与积分均由客户端处理，未提供商家后台或服务端账本。项目使用虚拟积分，没有支付、提现或现金兑奖。

## 浏览器运行

在项目根目录启动静态文件服务，例如已安装 Python 时：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

访问 <http://127.0.0.1:4173/>。建议固定使用同一地址和端口，以恢复同一份本地账号数据。

## Android 构建与安装

需要 JDK 17 或 21、Android SDK 35 和 Build Tools 35.0.0。配置 `ANDROID_HOME`，或在 `android/local.properties` 设置 `sdk.dir`。最低支持 Android 6.0（API 23）。

在项目根目录执行：

```powershell
.\android\build.ps1
# 依赖已缓存时：.\android\build.ps1 -Offline
adb install -r .\artifacts\haoyun-guagua-debug.apk
```

也可使用 Android Studio 打开 `android/`。构建自动同步根目录网页和本地图片，无需运行静态服务器；修改网页后需重新构建 APK。

应用使用 WebViewAssetLoader 加载 APK 内的 HTTPS 本地资源，无 INTERNET 权限，不提供原生 JavaScript bridge。Android 返回键从设置页、票面页回到选票页，在选票页返回则退到后台。

输出为 debug 签名 APK，尚未提供正式发布签名和商店发行包。更多配置见 [Android 说明](android/README.md)。
